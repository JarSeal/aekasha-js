This page is for working on Ækasha itself: the engine, the toolkit, the dev tools and the Hub.
It covers the rules the repo holds itself to on top of the public coding standards, the checks
that enforce them, and how a change goes from a plan to a merge into `main`.

The agents' sources are the root [`CLAUDE.md`](repo:.claude/CLAUDE.md) (its Coding standards,
Versioning and Workflow), [`docs/plans/CLAUDE.md`](repo:docs/plans/CLAUDE.md) and
[`devTools/verify/CLAUDE.md`](repo:devTools/verify/CLAUDE.md). This page explains them for a
person. When one of them changes, check this page too.
