## Monitors under load

Only on this page (p804 D14's performance pass): 200 monitors with `interval: 0` in one
scheduler, as the number fields' box above. "Values change every frame" changes every bound value
each frame (each monitor writes its text), "Values stay" keeps them, "Stop" hides the scheduler.
The readout averages the last 120 frame times. Phase 4 section 1 measured it; the plan has the
figures.
