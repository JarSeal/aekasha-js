# Font credits

The toolkit's fonts (p391 D7), each a static WOFF from IBM's npm package of the IBM Plex family (the family the UI kit ships as a variable WOFF2). Each folder holds the font, its `LICENSE.txt` (its name table's fields, written by `yarn importFont`) and its `OFL.txt` (the SIL Open Font License 1.1, the package's own text, which must travel with the font). A font added here gets a row.
